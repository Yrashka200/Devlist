# DevList

**DevList** is a simple community-driven page where developers can share their profiles, skills, and links.

## How to Add Your Profile

Want to be featured on DevList? You have two options:

### Option 1 — Fork the Repository

1. **Fork** this repository to your GitHub account.
2. Open the `script.js` file.
3. Find the `developers` array.
4. Add your own profile using the existing format.
5. Commit your changes.
6. Create a **Pull Request** to this repository.

Example:

```js
{
    id: 8,
    name: "Your Name",
    username: "@yourusername",
    age: 25,
    gender: "He/him",
    email: "your@email.com",
    website: "https://yourwebsite.com",
    twitter: "https://x.com/yourusername",
    github: "https://github.com/yourusername",
    avatarLetter: "Y",
    bio: "A short description about yourself.",
    stack: ["javascript", "react", "nodejs"]
}
```

Please make sure your profile follows the same structure as the existing profiles.

### Option 2 — Open an Issue

If you don't want to edit the code yourself, simply **open an Issue** in this repository.

Include your profile information:

* Name
* Username
* Age
* Pronouns
* Email
* Website
* GitHub
* X / Twitter
* Short bio
* Tech stack

A maintainer will add your profile to the project for you.

## Profile Requirements

Before submitting your profile:

* Make sure all provided information is correct.
* Use valid links to your GitHub, website, and social media.
* Keep your bio short and relevant to development.
* Only add technologies that you actually use.
* Follow the existing profile format.

## Contributing

Contributions are welcome!

You can contribute by:

* Adding your developer profile
* Fixing bugs
* Improving the UI
* Adding new features
* Improving documentation
* Reporting issues

If you find a bug or have an idea, feel free to **open an Issue**.
